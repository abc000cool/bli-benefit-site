# How Robust Is the BLI Benefit? — paper site

[bli-power-balance](https://github.com/abc000cool/bli-power-balance)
(archived at [doi:10.5281/zenodo.21435006](https://doi.org/10.5281/zenodo.21435006)).

Designed in Claude design; overlay logic runs dependency-free.
